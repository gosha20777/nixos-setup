# Аппаратная адаптация и энергосбережение: ThinkPad P1 Gen 2

Данный документ описывает аппаратные особенности, архитектуру гибридной графики, настройки энергоэффективности и устранение вендорных багов для ноутбука **Lenovo ThinkPad P1 Gen 2** (Type: `20QT002CRT` / близнец X1 Extreme Gen 2).

---

## 1. Спецификация оборудования

* **Процессор:** Intel Core i7-9750H (6 ядер / 12 потоков, базовая 2.60 GHz, до 4.50 GHz, Coffee Lake-H, TDP 45W).
* **Интегрированная графика (iGPU):** Intel UHD Graphics 630 (`PCI:0:2:0`, Device `8086:3e9b`).
* **Дискретная графика (dGPU):** NVIDIA Quadro T1000 Mobile (`PCI:1:0:0`, Device `10de:1fb9`, Turing TU117GLM, 4GB GDDR5).
* **Дисплей:** 15.6" 1920x1080 (панель BOE0853) @ 60 Hz.
* **Оперативная память:** 32 ГБ DDR4 (30.97 GiB доступно).
* **Накопитель:** 512 ГБ NVMe SSD Samsung PM981 (`/dev/nvme0n1`).
* **Связь:** Intel Wi-Fi 6 AX200 (`iwlwifi`), Bluetooth (`8087:0029`).

---

## 2. Физическая разводка видеовыходов и гибридная графика

Опрос шины DRM показал точную топологию материнской платы:
* **Внутренний экран (`eDP-1`):** Физически припаян к встроенному чипу **Intel UHD 630** (`card1`).
* **Внешний порт HDMI (`HDMI-A-1`) и порты Thunderbolt 3 (`DP-1`, `DP-2`):** Физически припаяны напрямую к дискретному чипу **NVIDIA Quadro T1000** (`card0`).

### Архитектурные следствия:
1. **Экран ноутбука работает ВСЕГДА:** Даже если видеокарта NVIDIA полностью отключена или обесточена, картинка на экране ноутбука никогда не погаснет, так как его отрисовывает Intel iGPU.
2. **Внешние мониторы требуют дискретку:** Сигнал на порт HDMI физически идет из чипа NVIDIA. Если попытаться вырезать карту устаревшими утилитами (`bbswitch`, `acpi_call`), видеосигнал на внешних мониторах пропадет полностью.
3. **Решение: NVIDIA Turing Runtime D3 (RTD3 / D3Cold):**
   * В автономном режиме (без внешнего монитора) дискретная карта автоматически переходит в состояние **D3Cold (физически обесточена, 0 Ватт)**.
   * При подключении HDMI-кабеля или запуске приложений с тяжелыми вычислениями через `nvidia-offload` драйвер NVIDIA мгновенно просыпается без перезагрузок системы.
   * Утилита **`nvidia-smi`** остается полностью работоспособной: при вызове она опрашивает статус GPU и позволяет карте снова уснуть.

### Конфигурация в `hosts/thinkpad/default.nix`:
```nix
services.xserver.videoDrivers = [ "nvidia" ];

hardware.nvidia = {
  modesetting.enable = true;
  powerManagement = {
    enable = true;
    finegrained = true; # Включает RTD3 / D3Cold (0 Ватт в простое)
  };
  open = false; # Закрытый драйвер гарантирует стабильный сон на Turing

  prime = {
    offload = {
      enable = true;
      enableOffloadCmd = true; # Предоставляет команду `nvidia-offload`
    };
    intelBusId = "PCI:0:2:0";
    nvidiaBusId = "PCI:1:0:0";
  };
};
```

## 3. Нативное управление процессором (CPU Power Management)

### Почему жесткая фиксация частоты — антипаттерн
Попытка зафиксировать процессор на базовой частоте (например, 2.6 ГГц) ухудшает автономность.  
В процессоре i7-9750H работает аппаратный драйвер **`intel_pstate` (Intel Speed Shift / HWP)**:
* **800 МГц в покое:** В простое ядра мгновенно сбрасывают частоту до 800 МГц и переходят в ультра-глубокие энергосберегающие C-состояния (C8–C10), где ядра практически обесточиваются (напряжение падает почти до 0 В).
* **Принцип «Race-to-sleep»:** Процессору выгоднее за 0.01 секунды выполнить полезную работу на повышенной энергоэффективной частоте и сразу уснуть обратно в 800 МГц, чем полсекунды монотонно крутить такты на искусственно ограниченной частоте под нагрузкой.

### Аппаратная связка без костылей:
Вместо самописных скриптов задействованы две официальные аппаратные ручки:
1. **Intel HWP EPP (Energy Performance Preference):** Аппаратный регистр процессора. В режиме экономии переводится в `power`, заставляя кристалл отдавать приоритет минимальному напряжению и задержке на 800 МГц.
2. **Lenovo ThinkPad ACPI `platform_profile`:** Встроенный контроллер (EC) ThinkPad аппаратно переводится в `low-power` (тихие вентиляторы, сниженный порог нагрева).
3. **Единый оркестратор — `services.power-profiles-daemon`:**
   Автоматическое переключение профилей по событиям сети/батареи через нативные udev-правила:
   ```nix
   services.udev.extraRules = ''
     SUBSYSTEM=="power_supply", ATTR{online}=="0", RUN+="${pkgs.power-profiles-daemon}/bin/powerprofilesctl set power-saver"
     SUBSYSTEM=="power_supply", ATTR{online}=="1", RUN+="${pkgs.power-profiles-daemon}/bin/powerprofilesctl set balanced"
   '';
   ```

## 4. Ограничение лимитов TDP через `services.throttled`

В прошивке BIOS ThinkPad зашит агрессивный баг троттлинга под Linux, сбрасывающий мощность до 15 Вт при кратковременном нагреве.  
Служба `throttled` (lenovo-throttling-fix) решает две задачи: устраняет баг и принудительно ограничивает аппетиты чипа при работе от аккумулятора:

```nix
services.throttled = {
  enable = true;
  extraConfig = ''
    [BATTERY]
    # Долговременный лимит PL1 на батарее: 20 Вт (вместо 45 Вт)
    PL1_Tdp_W = 20
    # Пиковый кратковременный лимит PL2 на батарее: 30 Вт
    PL2_Tdp_W = 30
    # Порог температуры: 80°C
    Trip_Temp_C = 80
  '';
};
```
Ноутбук на коленях остается абсолютно холодным и бесшумным.

## 5. Глубокий сон периферии и исправление багов оборудования

1. **Принудительный PCIe ASPM:**
   Параметр ядра переводит шины NVMe, Wi-Fi и контроллеров в L1-состояния энергосбережения при отсутствии передачи данных:
   ```nix
   boot.kernelParams = [ "pcie_aspm=force" ];
   ```
2. **Сон звукового кодека Intel HDA:**
   Звуковой тракт отключается через 1 секунду тишины (экономия ~1.5 Вт):
   ```nix
   boot.extraModprobeConfig = ''
     options snd_hda_intel power_save=1 power_save_controller=Y
     options iwlwifi power_save=1 uapsd_disable=0
   '';
   ```
3. **Фикс чтения батареи в initrd:**
   Исправление бага прошивки ThinkPad с некорректным отображением уровня заряда на раннем этапе загрузки:
   ```nix
   boot.initrd.availableKernelModules = [ "battery" ];
   ```
4. **Масштабирование дисплея (`hosts/thinkpad/home.nix`):**
   Для 15.6" панели 1080p в niri задан масштаб **`1.30`** (рассчитан по биометрической методике `display-scaling.md` под остроту зрения 0.3 и дистанцию 50 см).
