# Автоматический установщик и Live CD: Архитектура и запуск

Данный документ описывает устройство модульного TUI-установщика на Python, архитектуру загрузочного Live CD образа и пошаговый процесс развертывания NixOS на целевое оборудование.

---

## 1. Концепция установщика: Python MVC/MVVM

Вместо монолитных и трудноотлаживаемых shell-скриптов установщик спроектирован как **структурированное модульное Python-приложение** в каталоге `installer/`:

```
installer/
├── main.py                     # Центральная точка входа (CLI, флаги --execute, --mock, --log)
├── config.py                   # Глобальные пути (/mnt, /etc/iso/repo, имя пользователя)
├── models.py                   # Модели данных: DiskInfo, HostInfo, InstallConfig
├── theme.py                    # Визуальная тема Everforest Warm для библиотеки Rich
├── screens.py                  # Экраны интерфейса (Welcome, Host, Disk, Key, Password, Summary, Done)
├── progress.py                 # Пайплайн с живым стримингом вывода disko и nixos-install
│
├── services/                   # Системный слой команд (Services)
│   ├── executor.py             # CommandExecutor: dry-run по умолчанию, стриминг и лог-файл
│   ├── hardware_service.py     # Парсинг дисков через lsblk -J, проверка UEFI, памяти RAM
│   ├── host_service.py         # Автообнаружение хостов из каталога hosts/ репозитория
│   ├── disko_service.py        # Разметка и монтирование через Disko
│   ├── secrets_service.py      # Раскладка мастер-ключа Age (keys.txt) с правами 0600
│   ├── nixos_service.py        # Установка базовой системы (nixos-install) и смена пароля
│   └── repo_service.py         # Развертывание репозитория в ~/Projects/nixos-setup
│
└── tests/                      # 32 изолированных юнит-теста на pytest (dry-run, tmpdir)
```

## 2. Безопасность и архитектура выполнения

### А. Принцип Dry-Run по умолчанию
* Любой запуск установщика по умолчанию работает в **режиме симуляции (dry-run)**.
* Команды форматирования дисков, разбивки разделов и установки **не выполняются**, а лишь фиксируются в аудиторском журнале.
* **Единственный способ включить реальное выполнение:** передать явный флаг `--execute`.

### Б. Живой стриминг вывода долгих команд
В отличие от классических установщиков, где долгая сборка замирает со спиннером:
* Долгие шаги (`disko`, `nixos-install`) выполняются через метод `run_streaming()`.
* В интерфейсе Rich открывается Live-панель `[accent]▼ live output[/accent]`, где построчно отображается реальный вывод Nix (скачивание пакетов, компиляция).
* Каждая строка вывода параллельно пишется в журнал с точными таймстампами.

### В. Защита паролей и учетных данных
* При вводе пароля пользователя целевой системы (`PasswordPromptScreen`) пароль передается в команду `chroot /mnt chpasswd` **строго через stdin**.
* В лог-файл попадает только факт вызова команды `chroot /mnt chpasswd`, а сам пароль ни при каких условиях не логируется.

### Г. Журналирование и обработка ошибок
* Лог-файл по умолчанию: `/tmp/nixos-installer.log`.
* При возникновении ошибки класс `InstallError` перехватывает **последние 30 строк вывода (tail)** и отображает их в красной рамке на экране с указанием полного пути к логу, предлагая открыть диагностический shell.

## 3. Устройство Live CD образа (`modules/installer/default.nix`)

Загрузочный образ создается как полнофункциональная система для «ощупывания» финальной ОС:

1. **Полноценный рабочий стол в Live-режиме:**
   * Образ импортирует общий `hosts/common.nix` — композитор `niri`, шелл `Noctalia`, терминал `kitty`, палитра `Everforest Warm` и все программы присутствуют прямо в Live-сессии.
   * **Автологин:** система загружается напрямую в рабочий стол niri без экрана блокировки под пользователем `gosha20777`.
2. **Аппаратная поддержка и сеть из коробки:**
   * Профиль `installation-cd-minimal.nix` автоматически включает сканирование всех драйверов ядра (Wi-Fi, NVMe, тачпады).
   * Сеть настраивается через NetworkManager (включая консольный интерфейс `nmtui`).
3. **Фикс рендеринга шрифтов:**
   * Профиль минимального инсталлятора Nixpkgs принудительно отключает fontconfig (`mkOverride 500 false`).
   * В `modules/installer/default.nix` добавлено принудительное включение:
     ```nix
     fonts.fontconfig.enable = lib.mkForce true;
     ```
     Благодаря этому Kitty подхватывает `JetBrainsMono Nerd Font`, а символы Starship отображаются идеально.
4. **Изоляция секретов (sops gating):**
   * В Live-образе ключ Age отсутствует, поэтому опция `systemSettings.sops.enable = false;` отключает активацию секретов sops.
   * Это предотвращает сбои активации Home Manager и гарантирует, что скрипт посева обоев (`~/Pictures/Wallpapers/01.jpg`) отрабатывает до конца.
5. **Запеченный репозиторий и лаунчер:**
   * Репозиторий флейка (включая исходники `installer/`) копируется в образ по пути `/etc/iso/repo`.
   * На системный PATH выведена единая команда-лаунчер **`nixos-installer`**.
   * При открытии терминала Fish выводит подсказку:
     `🌲 NixOS Everforest Live — для запуска установщика выполните: nixos-installer`.

## 4. Сборка образа и запись на носитель

### Сборка ISO на рабочей машине:
```bash
nix build "path:.#nixosConfigurations.live-x86_64.config.system.build.isoImage" -o result-iso
```
Готовый образ появляется в `result-iso/iso/nixos-minimal-*.iso` (размер ~5.7 ГБ со всем рабочим столом и приложениями, сжатие zstd).

### Запись на флешку:

#### Вариант А: Ventoy (Рекомендуется)
1. Установить Ventoy на флешку.
2. Просто скопировать файл `.iso` на раздел Ventoy.

#### Вариант Б: Прямая запись через dd с синхронизацией
```bash
sudo dd if=result-iso/iso/nixos-minimal-*.iso of=/dev/sdX bs=4M status=progress conv=fsync
sync
```

## 5. Пошаговый процесс установки системы

1. **Загрузка с Live USB:**
   * На ThinkPad нажать `F12` при включении и выбрать флешку.
   * Загружается Live-окружение с автологином в niri.
2. **Проверка окружения и сеть:**
   * При необходимости подключиться к Wi-Fi: открыть терминал (`Super+Return`) и выполнить `nmtui`.
3. **Запуск мастера установки:**
   * В терминале ввести:
     ```bash
     nixos-installer
     ```
   * **Шаг 1 (Хост):** Выбрать `1` (`thinkpad`).
   * **Шаг 2 (Диск):** Выбрать целевой NVMe накопитель `/dev/nvme0n1`.
   * **Шаг 3 (Секреты):** Ввести приватный мастер-ключ Age (`AGE-SECRET-KEY-1...`) из резервной копии.
   * **Шаг 4 (Пароль):** Задать пароль пользователя целевой системы.
   * **Шаг 5 (Подтверждение):** Ознакомиться с параметрами и ввести `yes`.
4. **Выполнение установки:**
   * Мастер в реальном времени отобразит разметку Disko, копирование пакетов и настройку репозитория.
5. **Финал:**
   * Выбрать `Reboot` и извлечь флешку.
   * Ноутбук загрузится в готовую рабочую NixOS со всеми расшифрованными секретами OMP и SSH.
